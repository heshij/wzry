# 06 — 响应式体验打磨与 PWA 品牌化

**What to build:** 全流程多端体验收尾：按「移动端（竖屏单手）> 平板 > 桌面端」的优先级做响应式适配（大屏内容限宽居中、结果卡片多列、桌面键盘友好）；抽签揭晓动画与拇指区主操作；应用更名与品牌信息（应用名、描述、主题色、图标、页面标题与 PWA manifest）；深色模式检查；「添加到主屏幕」与断网可用性验证。

**涉及页面/文件：** 各业务页面（`/`、`/hero`、`/team`、`/pool`、`/history`）的交互与视觉打磨、`app/constants/index.ts` 与 `app/config/pwa.ts`（品牌信息）、`nuxt.config.ts`（标题/主题色）。

**Blocked by:** 01、02、03、04、05（全部功能切片完成后收尾）

**Status:** done（2026-09-29 实现、浏览器验收与代码审查完成；收尾复核通过）

- [ ] 抽签有短暂滚动/揭晓动画，结果出现有仪式感且不拖慢连续操作
- [ ] 移动端：主操作按钮位于竖屏拇指可及区，除输入昵称外全流程单手可完成
- [ ] 平板（768~1024px）：内容限宽居中，结果卡片多列排布，不拉伸变形
- [ ] 桌面端（≥1280px）：布局居中不溢出，鼠标点击全流程顺畅，昵称输入支持回车提交
- [ ] 应用名、描述、主题色、图标更新为本应用品牌（含 PWA manifest 与页面标题）
- [ ] 手机浏览器可「添加到主屏幕」，独立窗口打开显示正确名称与图标
