# 04 — 自定义英雄池

**What to build:** 用户可以创建/重命名/删除自定义英雄池，并从内置全英雄中勾选池成员；抽英雄前可选择使用「全部英雄」或某个自定义池，首次抽签与重抽都只在该范围内进行；池内英雄不足时明确阻止并提示。池数据本地持久化。

**涉及页面/文件：** `app/pages/pool.vue`（新建）、英雄池状态（Pinia store，如 `app/stores/pool.ts`）、`app/pages/hero.vue`（增加英雄池选择与校验）、首页增加「英雄池」入口。

**Blocked by:** 01 — 抽英雄最小闭环；02 — 抽英雄重抽（重抽同样受所选池约束）

**Status:** done（2026-09-29 实现、浏览器验收与代码审查完成；收尾复核通过）

- [ ] 英雄池管理页（`/pool`）：展示全部英雄与自定义池列表
- [ ] 可新建、重命名、删除自定义池；删除需二次确认
- [ ] 池编辑：从全英雄中勾选/取消成员，实时显示已选数量
- [ ] 抽英雄页可选择英雄池（默认「全部英雄」），选择结果被本地记住
- [ ] 首次抽签与两种重抽都只在所选池内进行
- [ ] 池内英雄数 < 玩家数时禁止开始并提示原因
- [ ] 自定义池刷新/重开页面后仍在
