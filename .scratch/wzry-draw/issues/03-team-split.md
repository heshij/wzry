# 03 — 抽队友闭环

**What to build:** 用户输入玩家名单并设置每队人数，随机均分成两队并分栏清晰展示；支持重新分组。默认每队 5 人（10 个槽位），每队人数可按 1~5 调节，槽位数随设置联动。

**涉及页面/文件：** `app/pages/team.vue`（新建）、复用 01 的玩家名单编辑组件（新增每队人数设置）、分队算法纯函数及其单元测试、首页增加「抽队友」入口。

**Blocked by:** 01 — 抽英雄最小闭环（复用玩家名单输入组件与导航骨架）

**Status:** done（2026-09-29 实现、浏览器验收与代码审查完成；收尾复核通过）

- [ ] 首页提供「抽队友」入口；抽队友页默认每队 5 人（10 个槽位）
- [ ] 每队人数可调（1~5），槽位数随之联动
- [ ] 名单人数恰好等于两队总容量时，两队人数均等
- [ ] 名单人数不足/超出容量时按实际人数随机均分；人数为奇数时随机一队多 1 人，并给出明确提示
- [ ] 结果以两栏/两张卡片清晰展示两队成员
- [ ] 「重新分组」可再次随机
- [ ] 分队算法为纯函数并有单元测试：两队人数差 ≤ 1、成员不重不漏
