# 05 — 抽签历史

**What to build:** 抽英雄与抽队友每次完成后自动保存记录；历史页按时间倒序展示，可展开查看详情、可一键清空（二次确认）；本地保存，最多保留最近 100 条，超出自动丢弃最旧记录。

**Blocked by:** 01 — 抽英雄最小闭环；03 — 抽队友闭环
