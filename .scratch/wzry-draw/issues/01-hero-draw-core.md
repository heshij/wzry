# 01 — 抽英雄最小闭环

**What to build:** 用户可以在手机上输入玩家名单（默认 5 人，可增删改），从内置全英雄名单中为每位玩家随机抽一个英雄（同一次抽签内不重复），结果以醒目卡片展示；玩家名单自动本地记忆。这是第一个可完整演示的纵向切片：浏览器打开首页 → 进抽英雄 → 输入名单 → 点抽签 → 看到结果。包含内置英雄静态数据、纯函数抽签算法及其单元测试、首页入口与导航骨架。

**涉及页面/文件：** `app/pages/index.vue`（重写）、`app/pages/hero.vue`（新建）、英雄数据常量（新建，如 `app/constants/heroes.ts`）、抽签算法纯函数（新建，如 `app/utils/draw.ts`）、玩家名单编辑组件（新建）。同时移除模板演示代码（Counter、InputEntry、Logos、`/hi`、`app/composables/count.ts` 等）。

**Blocked by:** None — can start immediately.
